# Aurum Atelier Scrollytelling

Immersive 3D scrollytelling experience for a luxury watch brand, built with React, React Three Fiber, Drei, and GSAP.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Highlights

- Glassmorphism UI overlay with cinematic typography
- ScrollTrigger-driven exploded view and technical focus
- GPU-accelerated gold dust particles and post-processing bloom
